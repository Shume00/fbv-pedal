# fbv-pedal

---

<h3>Disclaimer:</h3>
<h4>Make sure PIN0 is disconnected when flashing your Arduino with USB</h4>

---

<h3>Hardware used:</h3>
<ul>
  <li>Arduino Uno</li>
  <li>2x MAX485 TTL to RS-485</li>
  <li>RJ45 Breakout connector or board</li>
  <li>2x SPST Normally Open Foot Switches</li>
  <li>SSD1306 OLED Display</li>
  <li>Wire</li>
</ul>
